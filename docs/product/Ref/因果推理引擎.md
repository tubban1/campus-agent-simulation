# 因果推理引擎（causal_reasoning_rs）

> 基于 Rust 实现的因果推理引擎，提供因果图构建、do-calculus 干预计算、反事实推理三大核心能力，可独立集成或作为万象引擎子系统使用。

## 概述

因果推理引擎（`causal_reasoning_rs`）是万象认知体系中负责"因果层面"推理的独立 Rust 库。与传统的统计相关性分析不同，本引擎聚焦于**因果关系发现**与**干预效果估计**，核心代码集中在 `lib.rs`（约 13KB）。

主要解决以下问题：
- 变量之间的因果结构是什么？（因果图学习）
- 如果我干预变量 X，Y 会如何变化？（do-calculus）
- 如果当时 X 没有发生，Y 会是什么结果？（反事实推理）

## 核心架构

### 模块总览

| 模块 | 职责 | 关键数据结构 |
|------|------|-------------|
| `CausalGraph` | 因果图构建与管理 | 有向无环图（DAG） |
| `DoCalculus` | 干预概率计算 | P(Y \| do(X)) |
| `Counterfactual` | 反事实推理 | 反事实世界模型 |
| `DSeparation` | d-分离判定 | 条件独立检验 |
| `StructureLearning` | 因果结构发现 | PC/FCI 算法 |

### 核心接口

```rust
/// 因果推理引擎主入口
pub struct CausalReasoner {
    graph: CausalGraph,

    /// 条件独立检验
    pub fn is_independent(&self, x: &Variable, y: &Variable, given: &[Variable]) -> bool;

```

## 详细说明

### 因果图（CausalGraph）

因果图以有向无环图（DAG）表示变量间的因果关系。每条边 X → Y 表示 X 是 Y 的直接原因。

```rust
pub struct CausalGraph {
    nodes: Vec<CausalNode>,
    edges: Vec<CausalEdge>,
    adj_list: HashMap<NodeId, Vec<NodeId>>,
}

pub struct CausalNode {
    pub id: NodeId,
    pub name: String,
    pub var_type: VariableType,  // Continuous / Discrete / Binary
}

pub struct CausalEdge {
    pub from: NodeId,
    pub to: NodeId,
    pub weight: f64,
    pub edge_type: EdgeType,  // Direct / Confounded / Instrumental
}
```

**支持操作**：
- `add_node` / `add_edge`：手动构建因果图
- `parents(node)` / `children(node)`：查询因果邻域
- `ancestors(node)` / `descendants(node)`：追溯因果链
- `topological_sort()`：拓扑排序（因果序）
- `has_cycle()`：环检测（DAG 合法性校验）

### do-calculus 干预计算

do-calculus 是 Pearl 提出的因果干预形式化框架。`do(X=x)` 表示将变量 X 强制设为 x，切断 X 的所有父节点对 X 的影响。

**do-calculus 三规则**：

| 规则 | 名称 | 条件 |
|------|------|------|
| Rule 1 | 插入/删除观察 | Z 在 (X,Y) 间 d-分离 |
| Rule 2 | 因子分解替换 | Z 满足后门准则 |
| Rule 3 | 插入/删除干预 | Z 无后代且满足条件 |

## 应用案例

### 案例 1：营销策略因果评估

```rust
use causal_reasoning_rs::*;

let mut reasoner = CausalReasoner::new();

// 构建因果图：广告投入 → 品牌认知 → 购买决策
reasoner.build_graph(&[
    Variable::binary("ad_spend"),
    Variable::binary("brand_awareness"),
    Variable::binary("purchase"),
    Variable::continuous("revenue"),
])?;

reasoner.add_edge("ad_spend", "brand_awareness", 0.7)?;
reasoner.add_edge("brand_awareness", "purchase", 0.6)?;
reasoner.add_edge("purchase", "revenue", 0.9)?;
reasoner.add_edge("ad_spend", "purchase", 0.3)?; // 直接效应

// 干预：如果强制增加广告投入
let effect = reasoner.intervene(Intervention {
    variable: "ad_spend".into(),
    value: Value::Binary(true),
    conditions: vec![],
})?;

println!("P(purchase | do(ad_spend=high)) = {}", effect);
```

### 案例 2：反事实医疗决策

```rust
// 如果患者没有接受手术，存活率会是多少？
let counterfactual = reasoner.counterfactual(
    CounterfactualPremise {
        variable: "treatment".into(),
        actual_value: Value::Binary(true),   // 实际接受了手术
        counterfactual_value: Value::Binary(false), // 假设未接受
    },
    Query::variable("survival_5yr"),
)?;

println!("5年存活率（未手术）: {}", counterfactual.distribution);
```

## 问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| `GraphContainsCycle` 错误 | 因果图中存在环 | 检查边定义，确保 DAG 无环 |
| `NotIdentifiable` 错误 | 干预效果不可识别 | 添加更多观察变量或假设 |
| 结构学习结果不稳定 | 样本量不足或噪声过大 | 增加数据量，调高显著性阈值 |
| 反事实概率为 NaN | 条件概率表存在零概率 | 添加拉普拉斯平滑 |
| 性能瓶颈 | 图规模过大 | 使用稀疏表示，启用并行计算 |
