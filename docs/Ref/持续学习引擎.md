# 持续学习引擎（continual_learning_rs）

> 持续学习引擎，支持在线学习、增量训练、灾难性遗忘防护，使模型能在数据流中不断进化而不丢失已有知识。

## 概述

持续学习引擎（`continual_learning_rs`）解决机器学习中最棘手的问题之一：**灾难性遗忘**（Catastrophic Forgetting）。当模型在新数据上训练时，往往会覆盖旧知识。本引擎通过多种策略确保模型持续进化的同时保持已有能力。

项目包含完整的 `Cargo.toml` 配置和 `TECHNICAL_SPECIFICATION.md` 技术规格文档，核心代码 `lib.rs` 约 13KB。

## 核心架构

### 模块总览

| 模块 | 职责 | 关键机制 |
|------|------|---------|
| `online_learner` | 在线学习 — 逐样本/批次更新 | 流式梯度下降 |
| `incremental_trainer` | 增量训练 — 新任务/领域适配 | 参数隔离与共享 |
| `anti_forgetting` | 遗忘防护 — 知识保持策略 | EWC、回放、正则化 |
| `task_detector` | 任务边界检测 — 自动识别数据分布变化 | 漂移检测 |
| `memory_buffer` | 经验回放缓冲区 | 选择性样本保持 |
| `evaluation` | 持续学习评估指标 | 迁移/遗忘/扩展度量 |

### 核心接口

```rust
/// 持续学习引擎主入口
pub struct ContinualLearner {
    model: Box<dyn IncrementalModel>,
    strategy: Box<dyn LearningStrategy>,
    buffer: ExperienceBuffer,
    task_detector: TaskBoundaryDetector,
    metrics: ContinualMetrics,
}

impl ContinualLearner {
    /// 在线学习 — 处理单个数据点
    pub fn learn_one(&mut self, sample: &Sample) -> Result<LearnResult>;

    /// 增量训练 — 处理一批新数据（可能来自新任务）
    pub fn learn_batch(&mut self, batch: &Batch) -> Result<LearnResult>;

    /// 评估当前模型在所有已知任务上的表现
    pub fn evaluate_all(&self) -> Result<TaskPerformanceMap>;

    /// 获取遗忘度量
    pub fn forgetting_score(&self) -> f64;
}
```

## 详细说明

### 在线学习（OnlineLearner）

### 增量训练（IncrementalTrainer）

处理新任务/新领域的增量适配。

```rust
pub trait IncrementalModel {
    /// 在新任务数据上训练
    fn train_task(&mut self, task_id: TaskId, data: &Dataset) -> Result<()>;

    /// 多任务联合推理
    fn predict_all(&self, x: &FeatureVec) -> Result<Vec<(TaskId, Prediction)>>;

    /// 获取模型参数快照（用于回滚）
    fn snapshot(&self) -> ModelSnapshot;

    /// 恢复到指定快照
    fn restore(&mut self, snapshot: &ModelSnapshot) -> Result<()>;
}

pub struct IncrementalConfig {
    pub strategy: IsolationStrategy,
    pub shared_layers_ratio: f64,  // 底层共享比例
    pub task_specific_lr: f64,
}

pub enum IsolationStrategy {
    FullIsolation,      // 每个任务独立模型
    SharedBottom,       // 共享底层，任务特定顶层
    AttentionRouting,   // 注意力路由（软隔离）
    AdapterModules,     // 适配器模块（参数高效）
}
```

#### Elastic Weight Consolidation (EWC)

```rust
pub struct EwcStrategy {
    importance: HashMap<ParamId, f64>,  // Fisher 信息量
    reference_params: HashMap<ParamId, f64>,
    ewc_lambda: f64,  // 正则化强度
}

// 损失函数: L_total = L_new + λ * Σ_i F_i * (θ_i - θ*_i)²
// F_i 是参数 θ_i 的 Fisher 信息量，θ* 是旧任务最优参数
```

#### 经验回放（Experience Replay）

```rust
pub struct ReplayStrategy {

pub enum ReplaySampling {

    ClassBalanced,     // 类别均衡
    Herding,           // 代表性样本（iCaRL）
    GradientBased,     // 梯度最优回放（GSS）
}

pub struct ExperienceBuffer {
    storage: Vec<StoredSample>,
    max_capacity: usize,
    eviction_policy: EvictionPolicy,
}
```

#### 知识蒸馏防护

```rust
pub struct DistillationStrategy {
    teacher_snapshot: ModelSnapshot,  // 旧模型作为教师
```

### 评估指标（Evaluation）

```rust

    /// 平均准确率（所有任务）
```

## 应用案例

### 案例 1：流式文本分类

```rust
use continual_learning_rs::*;

let mut learner = ContinualLearner::builder()
    .with_model(LinearModel::new(768, 10))
    .with_strategy(EwcStrategy::new(lambda = 1000.0))
    .with_buffer(ExperienceBuffer::with_capacity(5000))
    .with_drift_detector(DriftDetector::ADWIN)
    .build();

// 模拟数据流：先学体育，再学科技，再学娱乐
for topic in &["sports", "tech", "entertainment"] {
    let dataset = load_topic_data(topic)?;
    for sample in dataset.iter() {
        learner.learn_one(sample)?;
    }
    println!("学完 {} 后遗忘度: {:.4}", topic, learner.forgetting_score());
}

// 评估所有任务
let metrics = learner.evaluate_all()?;
println!("平均准确率: {:.2}%, 遗忘度: {:.4}",
    metrics.average_accuracy * 100.0,
    metrics.average_forgetting);
```

### 案例 2：多任务增量训练

```rust
let mut learner = ContinualLearner::builder()
    .with_model(NeuralModel::new(&[784, 256, 128, 10]))
    .with_strategy(ReplayStrategy::new(
        ExperienceBuffer::with_capacity(10000),
        ReplaySampling::ClassBalanced,
    ))
    .with_isolation(IsolationStrategy::AdapterModules)
    .build();

// 任务 1: MNIST
learner.learn_batch(&load_mnist()?)?;

// 任务 2: Fashion-MNIST（增量，不重训任务 1）
learner.learn_batch(&load_fashion_mnist()?)?;

// 任务 3: SVHN（增量）
learner.learn_batch(&load_svhn()?)?;

// 检查各任务表现
let metrics = learner.evaluate_all()?;
for (task_id, acc) in &metrics.per_task_accuracy {
    println!("任务 {}: {:.1}%", task_id, acc * 100.0);
}
```

## 问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 遗忘度持续升高 | EWC λ 过小或回放缓冲区太小 | 增大 λ 或扩大 buffer 容量 |
| 新任务学习缓慢 | 正则化约束过强 | 降低 ewc_lambda，减少共享层比例 |
| 任务边界检测延迟 | 漂移检测窗口过大 | 减小 window_size，使用更敏感的检测器 |
| 内存溢出 | 回放缓冲区无上限 | 设置 max_capacity，启用淘汰策略 |
| 模型快照占用大量磁盘 | 快照过于频繁 | 降低快照频率，启用增量快照 |
| 多任务间负迁移严重 | 任务相关性低但强制共享 | 改用 FullIsolation 或降低 shared_layers_ratio |
