# 涌现认知引擎（emergent_cognition_rs）

> 涌现认知引擎，从简单规则的交互中自发产生复杂认知行为——不预设智能，让智能自己长出来。

## 概述

涌现认知引擎（`emergent_cognition_rs`）采用与传统自上而下认知架构完全不同的范式：**自下而上的涌现**。不预先定义"记忆"、"推理"、"决策"等模块，而是定义一组简单的认知元（cognitive primitives）和交互规则，让复杂认知行为从大量元胞的交互中自发涌现。核心代码 `lib.rs` 约 16KB。

**核心理念**：
- 意识是涌现的，不是设计的
- 简单规则 + 大量交互 = 复杂行为
- 不预设功能模块，让功能自己分化
- 受复杂系统理论、元胞自动机、活性物质（active matter）启发

## 核心架构

### 基本组件

```
CognitivePrimitive（认知元）
    ↓ 交互规则
PrimitiveNetwork（元胞网络）
    ↓ 自组织
EmergentStructure（涌现结构）
    ↓ 功能分化
CognitiveBehavior（认知行为）
```

### 模块总览

| 模块 | 职责 | 关键概念 |
|------|------|---------|
| `primitive` | 认知元定义 | 激活、抑制、扩散 |
| `network` | 元胞网络拓扑 | 小世界、无标度 |
| `dynamics` | 网络动力学 | 吸引子、分岔、混沌 |
| `self_org` | 自组织机制 | Hebb 学习、STDP |
| `emergence` | 涌现检测与分析 | 序参量、相变 |
| `behavior` | 行为映射 | 涌现结构→认知功能 |

### 核心接口

```rust
/// 涌现认知引擎主入口
pub struct EmergentCognition {
    network: PrimitiveNetwork,
    dynamics: NetworkDynamics,
    self_org: SelfOrganization,
    emergence_detector: EmergenceDetector,
    config: EmergentConfig,
}

impl EmergentCognition {
    /// 创建新的涌现认知系统
    pub fn new(config: EmergentConfig) -> Self;

    /// 注入刺激（输入）
    pub fn stimulate(&mut self, stimulus: Stimulus) -> Result<()>;

    /// 运行一个时间步
    pub fn step(&mut self) -> Result<SystemState>;

    /// 运行多个时间步
    pub fn run(&mut self, steps: usize) -> Result<Vec<SystemState>>;

    /// 检测当前涌现结构
    pub fn detect_emergence(&self) -> Result<EmergenceReport>;

    /// 读取系统当前"认知状态"
    pub fn cognitive_state(&self) -> Result<CognitiveState>;
}
```

## 详细说明

### 认知元（CognitivePrimitive）

系统的最小单元，每个认知元有简单的内部状态和交互规则。

```rust
pub struct CognitivePrimitive {
    pub id: PrimitiveId,
    pub state: PrimitiveState,
    pub activation: f64,         // 激活水平 [0, 1]
    pub threshold: f64,          // 激活阈值
    pub decay_rate: f64,         // 自然衰减率
    pub connections: Vec<Synapse>, // 与其他元的连接
    pub primitive_type: PrimitiveType,
}

pub enum PrimitiveType {
    Excitatory,    // 兴奋型 — 激活邻居
    Inhibitory,    // 抑制型 — 抑制邻居
    Modulatory,    // 调节型 — 调节连接权重
    Sensory,       // 感觉型 — 接收外部输入
    Motor,         // 运动型 — 输出到外部
}

pub struct Synapse {
    pub target: PrimitiveId,
    pub weight: f64,          // 连接权重
    pub delay: usize,         // 信号传导延迟（时间步）
    pub plasticity: PlasticityRule,
}
```

### 网络拓扑（PrimitiveNetwork）

```rust
pub struct PrimitiveNetwork {
    primitives: HashMap<PrimitiveId, CognitivePrimitive>,
    topology: NetworkTopology,
    spatial_index: SpatialIndex,  // 空间索引（加速邻域查询）
}

pub enum NetworkTopology {
    /// 规则网格 — 类似皮层柱状结构
    RegularGrid { dims: (usize, usize) },
    /// 小世界网络 — 高聚类 + 短路径
    SmallWorld { k: usize, beta: f64 },
    /// 无标度网络 — 少数高度数枢纽
    ScaleFree { m: usize },  // 每条新边连接 m 个已有节点
    /// 自适应拓扑 — 连接随活动动态变化
    Adaptive { max_connections: usize },
}

impl PrimitiveNetwork {
    /// 添加认知元
    pub fn add_primitive(&mut self, primitive: CognitivePrimitive);

    /// 添加连接
    pub fn add_synapse(&mut self, from: PrimitiveId, to: PrimitiveId, weight: f64);

    /// 获取活跃区域（激活水平高于阈值的元及其邻域）
    pub fn active_region(&self) -> Vec<&CognitivePrimitive>;

    /// 网络规模
    pub fn size(&self) -> usize;
}
```

### 网络动力学（NetworkDynamics）

定义认知元状态如何随时间演化。

```rust
pub struct NetworkDynamics {
    update_rule: UpdateRule,
    noise_level: f64,
    global_inhibition: f64,  // 全局抑制（模拟资源竞争）
}

pub enum UpdateRule {
    /// 阈值激活 — 超过阈值则激活，否则衰减
    ThresholdActivation,
    /// Sigmoid 激活 — 连续平滑激活
    Sigmoid { gain: f64 },
    /// Hopfield 吸引子网络 — 能量最小化
    Hopfield,
    /// 脉冲神经网络（简化 Izhikevich）
    SpikingIzhikevich,
    /// Boolean 网络 — 离散状态
    BooleanNetwork,
}

impl NetworkDynamics {
    /// 执行一个时间步的状态更新
    pub fn step(&self, network: &mut PrimitiveNetwork) -> Result<()>;

    /// 计算网络能量（Hopfield 网络）
    pub fn energy(&self, network: &PrimitiveNetwork) -> f64;

    /// 检测是否处于吸引子状态
    pub fn is_attractor(&self, network: &PrimitiveNetwork) -> bool;
}
```

### 自组织（SelfOrganization）

连接权重如何根据活动模式自适应调整。

```rust
pub struct SelfOrganization {
    rules: Vec<Box<dyn PlasticityRule>>,
    structural_plasticity: StructuralPlasticity,
}

pub trait PlasticityRule {
    /// 根据前后元活动更新突触权重
    fn update_weight(
        &self,
        pre_activation: f64,
        post_activation: f64,
        current_weight: f64,
    ) -> f64;
}

/// Hebb 学习 — "一起激活的元连在一起"
pub struct HebbianRule {
    pub learning_rate: f64,
    pub weight_limit: f64,
}

/// STDP — 脉冲时序依赖可塑性
pub struct StdpRule {
    pub tau_plus: f64,   // 长时程增强时间常数
    pub tau_minus: f64,  // 长时程抑制时间常数
    pub a_plus: f64,
    pub a_minus: f64,
}

/// 结构可塑性 — 动态创建/删除连接
pub struct StructuralPlasticity {
    pub growth_rate: f64,     // 新连接生长率
    pub pruning_threshold: f64, // 弱连接修剪阈值
    pub max_connections: usize,
}
```

### 涌现检测（EmergenceDetector）

如何判断系统中是否发生了涌现。

```rust
pub struct EmergenceDetector {
    detectors: Vec<Box<dyn EmergenceMetric>>,
    phase_transition_monitor: PhaseTransitionMonitor,
}

pub trait EmergenceMetric {
    /// 计算涌现度（0 = 完全随机，1 = 完全有序）
    fn compute(&self, network: &PrimitiveNetwork) -> f64;
}

pub struct EmergenceReport {
    /// 全局序参量（order parameter）
    pub order_parameter: f64,
    /// 功能聚类数
    pub functional_clusters: usize,
    /// 信息整合度（Φ 值，类似 IIT 理论）
    pub integration_phi: f64,
    /// 是否处于临界态（criticality）
    pub is_critical: bool,
    /// 涌现的宏观模式
    pub macro_patterns: Vec<MacroPattern>,
}

/// 相变监测 — 检测系统是否处于有序-无序临界点
pub struct PhaseTransitionMonitor {
    pub critical_exponents: CriticalExponents,
    pub finite_size_scaling: bool,
}
```

**涌现度量指标**：

| 指标 | 含义 | 高值表示 |
|------|------|---------|
| `order_parameter` | 序参量 | 全局同步/有序 |
| `integration_phi` | 信息整合度 | 系统不可还原为部分之和 |
| `functional_clusters` | 功能聚类数 | 功能分化程度 |
| `entropy_rate` | 熵率 | 信息产生速率 |
| `correlation_length` | 关联长度 | 远程关联范围 |

## 应用案例

### 案例 1：基础涌现实验

```rust
use emergent_cognition_rs::*;

// 创建 1000 个认知元的小世界网络
let config = EmergentConfig {
    network_size: 1000,
    topology: NetworkTopology::SmallWorld { k: 6, beta: 0.3 },
    update_rule: UpdateRule::Sigmoid { gain: 4.0 },
    noise_level: 0.05,
    plasticity: vec![Box::new(HebbianRule::new(0.01, 1.0))],
    ..Default::default()
};

let mut engine = EmergentCognition::new(config);

// 注入周期性刺激
for step in 0..10000 {
    if step % 100 < 10 {
        engine.stimulate(Stimulus::pattern(vec![0, 1, 2, 3, 4]))?;
    }
    engine.step()?;
}

// 检测涌现结构
let report = engine.detect_emergence()?;
println!("序参量: {:.3}", report.order_parameter);
println!("功能聚类: {}", report.functional_clusters);
println!("信息整合度 Φ: {:.3}", report.integration_phi);
println!("临界态: {}", report.is_critical);
```

### 案例 2：模式分类涌现

```rust
// 让系统自发学会区分不同输入模式
let mut engine = EmergentCognition::new(EmergentConfig {
    network_size: 2000,
    topology: NetworkTopology::ScaleFree { m: 3 },
    update_rule: UpdateRule::ThresholdActivation,
    plasticity: vec![
        Box::new(StdpRule::default()),
        Box::new(StructuralPlasticity::new(0.01, 0.05, 20)),
    ],
    ..Default::default()
});

// 训练：反复呈现两类刺激
for epoch in 0..100 {
    // 模式 A
    engine.stimulate(Stimulus::pattern(vec![0, 10, 20, 30]))?;
    engine.run(50)?;

    // 模式 B
    engine.stimulate(Stimulus::pattern(vec![5, 15, 25, 35]))?;
    engine.run(50)?;
}

// 测试：呈现模式 A 的部分，看是否能补全
engine.stimulate(Stimulus::partial(vec![0, 10], 40))?;
let state = engine.cognitive_state()?;
println!("模式补全结果: {:?}", state.active_pattern);
```

### 案例 3：观察功能分化

```rust
// 长期运行后分析功能分化
engine.run(100000)?;

let clusters = engine.analyze_functional_clusters()?;
for (i, cluster) in clusters.iter().enumerate() {
    println!("功能簇 {}:", i);
    println!("  大小: {} 个认知元", cluster.size);
    println!("  平均激活: {:.3}", cluster.mean_activation);
    println!("  响应偏好: {:?}", cluster.preferred_stimulus);
    println!("  可能功能: {:?}", cluster.inferred_function);
}
```

## 问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 系统始终无涌现 | 连接太稀疏或噪声太低 | 增加连接度 k，提高噪声水平 |
| 系统全局同步（癫痫态） | 兴奋过强/抑制不足 | 增大 global_inhibition，降低 gain |
| 涌现结构不稳定 | 学习率过高 | 降低 Hebbian learning_rate，增加 decay |
| 功能不分化 | 缺少结构可塑性 | 启用 StructuralPlasticity |
| 模拟速度过慢 | 网络规模过大 | 使用稀疏更新（只更新活跃元邻域） |
| 无法检测相变 | 采样频率不足 | 增加监测频率，启用有限尺度缩放分析 |

## 设计哲学

涌现认知引擎的核心信念：

1. **不做预设**：不预先定义"这是记忆模块"、"那是推理模块"
2. **简单规则**：每个认知元只有激活/抑制/衰减三个基本行为
3. **量变到质变**：1000 个简单元的交互 → 复杂的宏观认知行为
4. **临界态优势**：系统在有序-无序临界点时计算能力最强
5. **身体性**：认知不是纯计算，需要与环境的交互（stimulus/response）
