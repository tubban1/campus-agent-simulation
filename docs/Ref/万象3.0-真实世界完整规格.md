# 万象 3.0：一个真实世界的完整规格

## 这份文档是什么

这不是"升级方案"。这是"真实世界如何运转"的完整描述，以及万象如何镜像它。每一节描述现实的一个面向，然后说明万象用什么机制复现它。没有硬编码、没有编剧、没有模板。世界从机制中自然生长。

---

## 一、空间与地理（世界的骨架）

### 现实

真实世界发生在**空间**里。空间不是标签，是结构：
- 地点之间有距离（影响一切：贸易成本、军事投射、信息速度、文化传播）
- 地形影响通行（山脉难越、河流可渡、海洋阻隔、平原畅通）
- 资源分布在特定地点（不是"势力有资源"，是"这个地方有矿"）
- 地理位置决定战略价值（关口、渡口、矿产地、肥沃平原）
- 距离产生隔离（远处的事和你无关，直到它传过来）

### 万象机制

```rust
pub struct WorldGeography {
    pub locations: BTreeMap<String, Location>,
    pub edges: BTreeMap<(String, String), Edge>,  // 两地间连接
}

pub struct Location {
    pub id: String,
    pub name: String,                    // 题材命名（GenreKit）
    pub terrain: String,                 // "山地"/"平原"/"海域"/"荒漠"/"密林"/"虚空"
    pub fertility: f64,                  // 土地肥力（食物产出基础）
    pub climate: f64,                    // 气候带（影响产出周期）
    pub deposits: Vec<Deposit>,          // 地下/地表资源
    pub controller: Option<String>,      // 当前控制势力
    pub population: u64,                 // 人口
    pub carrying_capacity: u64,          // 承载力（由肥力+资源+技术决定）
    pub infrastructure: f64,             // 基础设施水平（影响产出效率）
}

pub struct Edge {
    pub from: String,
    pub to: String,
    pub distance: f64,                   // 基础距离
    pub terrain_cost: f64,               // 地形加成（山地×3，平原×1，海域×2）
    pub passable: bool,                  // 是否可通行
    pub travel_time: u64,                // 通行需要几tick（距离×地形成本）
}

pub struct Deposit {
    pub resource: String,                // "灵石"/"合金"/"能源晶体"（题材决定）
    pub total_reserve: f64,              // 总储量
    pub extracted: f64,                  // 已开采量
    pub renewable: bool,                 // 可再生？
    pub regen_rate: f64,                 // 再生速率/tick
    pub extraction_difficulty: f64,      // 随开采深度上升
}
```

### 空间如何影响一切

- **贸易成本** = 资源价值 - 运输成本（距离 × 地形）。远距离贸易只有高价值资源才划算。
- **军事投射** = 力量 × 衰减（距离越远，能投射的军事力量越小）。远征天然劣势。
- **信息速度** = 每 tick 传播一跳（沿 edge）。远处事件延迟 = 最短路径的 edge 数。
- **文化传播** = 沿社交网络 + 地理邻接。邻居文化相似，远处文化分化。
- **扩张限制** = 控制新地点需要军事存在，距离越远维持成本越高。

### 确定性

locations/edges 在 spawn 时由种子 rng 生成（GenreKit 决定命名和地形分布）。之后不变（除非灾变改变地形）。BTreeMap 有序。

## 二、生态与人口（世界的生命基础）

### 现实

- 人口受资源约束（承载力）
- 人口有结构（年龄、技能分布）
- 人口会迁移（用脚投票：去更好的地方）
- 生态有周期（丰年/荒年、季节）
- 过度开发导致退化（土地荒漠化、资源枯竭）
- 瘟疫/灾害是密度依赖的（人口越密越容易爆发）

### 万象机制

```rust
pub struct PopulationDynamics {
    /// 每个地点的人口状态
    pub per_location: BTreeMap<String, LocationPopulation>,
    /// 全局环境周期
    pub climate_phase: f64,        // 0..2π，周期波动（影响全局产出）
    pub climate_period: u64,       // 多少tick一个周期
}

pub struct LocationPopulation {
    pub count: u64,
    pub birth_rate: f64,           // 受资源充裕度影响
    pub death_rate: f64,           // 受资源短缺/战争/瘟疫影响
    pub satisfaction: f64,         // 平均满意度（影响迁移意愿）
    pub skill_distribution: BTreeMap<String, f64>,  // 技能分布
    pub disease_risk: f64,         // 密度依赖：count/carrying_capacity
}
```

### 人口如何运转

```
每tick：
  对每个地点（按id排序）：
    // 产出
    food_production = fertility × climate_factor × infrastructure × labor
    resource_production = Σ(deposit.extraction_rate × workers_allocated)
    
    // 消耗
    food_consumption = population × per_capita_need
    resource_consumption = population × per_capita_need + military_upkeep
    
    // 人口变化
    if food_surplus > 0: birth_rate 上升（有余粮→生更多）
    if food_deficit > 0: death_rate 上升（饥荒）
    
    // 迁移（FEP驱动：个人决策"留还是走"）
    if satisfaction < threshold:
      观察邻居地点的条件（信息可能过时）
      如果预期别处更好 → 迁移（人口转移）
    
    // 承载力
    carrying_capacity = f(fertility, resources, technology)
    if population > carrying_capacity: 强制死亡/迁移
    
    // 瘟疫（密度依赖 + 随机触发）
    disease_risk = (population / carrying_capacity)^2 × base_risk
    if rng < disease_risk: 瘟疫爆发 → 多tick过程 → 人口下降
```

### 环境周期

```
climate_factor = 1.0 + 0.2 × sin(2π × tick / climate_period)
// 丰年（factor > 1）：产出多、人口增长、社会安定
// 荒年（factor < 1）：产出少、资源紧张、冲突增加
// 周期不是硬编码"每N tick来一次灾"——是连续波动，影响所有决策的背景条件
```

### 资源枯竭与发现

```
每tick开采：
  deposit.extracted += extraction_rate
  extraction_difficulty = base × (1 + extracted/total_reserve)  // 越挖越难
  if extracted >= total_reserve × 0.9: 产量急剧下降（枯竭预警）
  if extracted >= total_reserve: 矿竭 → 该资源停产 → 经济冲击

探索可发现新矿：
  FEP决策"探索" → 多tick过程 → 成功时：在随机地点发现新deposit
  （发现什么、在哪里由种子rng决定，确定性）
```

## 三、经济（世界的血液循环）

### 现实

- 不同地方产不同东西（比较优势）
- 贸易因为供需差发生（不是随机配对）
- 价格由稀缺度决定（不是固定值）
- 贸易路线一旦建立有惯性（制度）
- 垄断产生权力（控制稀缺资源）
- 不平等贸易产生怨恨
- 经济危机从信用崩溃/资源断裂涌现
- 技术改变生产函数（同样的投入产更多）

### 万象机制

```rust
pub struct Economy {
    /// 每个势力的经济状态
    pub faction_economies: BTreeMap<String, FactionEconomy>,
    /// 贸易路线（制度化的贸易）
    pub trade_routes: Vec<TradeRoute>,
    /// 价格信号（全局，由供需涌现）
    pub prices: BTreeMap<String, f64>,
}

pub struct FactionEconomy {
    pub controlled_locations: Vec<String>,   // 控制的地点（资源来源）
    pub stockpile: BTreeMap<String, f64>,    // 库存
    pub production: BTreeMap<String, f64>,   // 每tick产量（地点产出之和）
    pub consumption: BTreeMap<String, f64>,  // 每tick消耗
    pub labor_allocation: BTreeMap<String, f64>,  // 劳动力分配（采矿/农业/军事/研究）
    pub technology_level: BTreeMap<String, f64>,  // 各资源的生产技术
}

pub struct TradeRoute {
    pub id: String,
    pub from_faction: String,
    pub to_faction: String,
    pub goods_from: Vec<(String, f64)>,   // A给B什么、多少/tick
    pub goods_to: Vec<(String, f64)>,     // B给A什么、多少/tick
    pub established_tick: u64,
    pub trust_basis: f64,                  // 基于双方trust
    pub path: Vec<String>,                 // 经过哪些地点（影响成本）
}
```

### 价格如何涌现

```
每tick：
  对每种资源r：
    total_supply = Σ(各势力production[r])
    total_demand = Σ(各势力consumption[r])
    scarcity = demand / max(supply, ε)
    price[r] = base_value[r] × scarcity    // 稀缺→贵，过剩→贱
    
  价格影响决策：
    贵资源 → FEP中"获取该资源"的行动奖励↑
    贱资源 → FEP中"生产该资源"的行动奖励↓
    → 自然调节供需（看不见的手）
```

### 贸易如何发生

```
// 制度化贸易（惯性，不需要每tick决策）
对每条 trade_route：
  if 双方trust > 0.3 && 路线通行：
    执行贸易（资源转移，经守恒律）
    双方记入交互记忆（valence = 贸易利润/各自需求）
  else：
    路线中断 → 供需失衡 → 预测误差 → 可能触发新决策

// 新贸易开辟（FEP决策，只在预测误差高时）
当某势力有deficit且无既有路线满足：
  领袖FEP评估：
    - 向谁买？（有surplus + trust > 0 + 距离可接受）
    - 代价？（对方要什么？运输成本？）
    - 替代？（自己能产吗？能抢吗？）
  → 选择预期自由能最低的方案
```

### 经济危机如何涌现

```
不是硬编码"每N tick来一次危机"。是条件自然成熟：

路径1：资源枯竭
  某关键资源矿竭 → 依赖它的势力deficit飙升 → 贸易路线断裂
  → 连锁：依赖该势力的贸易伙伴也受影响 → 多米诺

路径2：垄断与反噬
  某势力控制稀缺资源 → 定价权 → 不平等贸易 → 买方trust下降
  → 买方FEP决策：找替代/结盟对抗/武力夺取
  → 垄断者的"安全"预测误差飙升（没想到对方会反抗）

路径3：过度扩张
  势力扩张太快 → 管理成本超线性 → 资源分散 → 各处deficit
  → 内部不满 → 分裂 → 经济碎片化

路径4：战争消耗
  长期战争 → 双方资源耗竭 → 贸易中断 → 第三方趁虚而入
```

## 四、信息（世界不是全知的）

### 现实

- 你只知道你看到的（局部）
- 消息传播需要时间（信使/口耳相传/媒体）
- 传播过程失真（以讹传讹）
- 有人故意欺骗（宣传/间谍/信息战）
- 信息不对称产生权力（知道别人不知道的）
- 信息封锁是武器（切断对方的信息源）

### 万象机制

```rust
pub struct InformationLayer {
    /// 每个agent的感知（不是世界真实状态）
    pub perceptions: BTreeMap<String, AgentPerception>,
    /// 信息传播队列（事件→沿网络扩散）
    pub propagation_queue: Vec<InfoPacket>,
}

pub struct AgentPerception {
    /// 我以为的各势力状态（可能过时/失真）
    pub believed_factions: BTreeMap<String, FactionSnapshot>,
    /// 我以为的各地点状态
    pub believed_locations: BTreeMap<String, LocationSnapshot>,
    /// 各方面信息的最后更新时间
    pub freshness: BTreeMap<String, u64>,
    /// 信息来源（谁告诉我的）
    pub sources: BTreeMap<String, String>,
    /// 不确定性（信息越旧→越不确定）
    pub uncertainty: BTreeMap<String, f64>,
}

pub struct InfoPacket {
    pub event_id: String,
    pub content: EventSummary,       // 可能被失真的内容
    pub origin: String,              // 原始发生地
    pub current_holder: String,      // 当前谁知道
    pub hops: u64,                   // 已传播几跳
    pub fidelity: f64,               // 保真度（每跳衰减）
    pub arrived_tick: u64,
}
```

### 信息传播规则

```
事件发生：
  → 直接参与者：立即、完整感知（fidelity=1.0）
  → 同地点其他人：同tick感知，fidelity=0.9（目击但有偏差）
  → 每tick：沿社交网络（高trust联系人）+ 地理邻接 扩散一跳
    每跳：fidelity ×= 0.85（失真）
    小概率（注入rng）：内容变异（"大胜"→"惨胜"，"贸易"→"朝贡"）
  → 距离远的：需要多tick才到达
  → 无社交连接且地理不邻接：永远不知道（信息孤岛）

信息衰减：
  每tick：uncertainty[key] += 0.02（信息自然过时）
  收到新信息：uncertainty[key] = 0, freshness[key] = now

欺骗（FEP决策）：
  agent可以选择 Action::SpreadDisinformation
  → 向特定对象发送虚假InfoPacket（fidelity故意设低/内容篡改）
  → 对方如果trust来源高 → 接受为真 → 基于错误信念决策 → 误判
```

### 信息如何影响决策

FEP 基于 `believed_state`（我以为的世界）决策，不是真实状态。
- 信念错误 → 决策错误 → 预测误差（下tick发现现实和预期不符）→ 重新决策
- 信息封锁 → 决策基于过时数据 → 系统性误判
- 欺骗成功 → 对方做出"理性但基于错误前提"的决策 → 对欺骗者有利

## 五、Agent 心智（世界的决策单元）

### 现实

- 人不是纯理性的（损失厌恶、情绪劫持、从众、现状偏见）
- 人的决策受性格影响（Big Five）
- 人有情绪（影响判断）
- 人有信念（可能是错的）
- 人有目标（可能冲突）
- 人有记忆（过去经验影响当前）
- 人有价值观/文化（模因影响偏好）
- 大部分时间人不做决策（惯性/习惯/制度）

### 万象机制

```rust
pub struct Agent {
    pub id: String,
    pub name: String,
    pub alive: bool,
    pub age: f64,
    pub location: String,
    pub faction: String,
    
    // 性格（spawn时种子rng生成，不变）
    pub personality: Personality,
    
    // 能力
    pub power_value: f64,
    pub skills: BTreeMap<String, f64>,
    
    // 大脑（已实现，需接线）
    pub brain: LivingBrain,              // FEP + 意识 + 量子 + 梦境 + 顿悟
    pub theory_of_mind: TheoryOfMindEngine,  // 对他者的信念建模
    pub counterfactual: CounterfactualEngine, // 反事实推理
    pub meme_profile: Vec<String>,       // 持有的模因
    
    // 情绪（每tick从预测误差更新）
    pub valence: f64,                    // 效价 (-1..1)
    pub arousal: f64,                    // 唤醒 (0..1)
    
    // 当前行为模式
    pub routine: Option<Action>,         // 惯性行为（预测误差低时执行）
    pub last_decision_tick: u64,         // 上次主动决策是什么时候
    
    // 感知
    pub perception: AgentPerception,
    
    // 交互记忆
    pub memories: BTreeMap<String, InteractionMemory>,  // 对每个其他entity的记忆
}

pub struct Personality {
    pub openness: f64,           // 开放性：探索/新事物的奖励权重
    pub conscientiousness: f64,  // 尽责性：维持现状/遵守制度的奖励权重
    pub extraversion: f64,       // 外向性：社交行动的奖励权重
    pub agreeableness: f64,      // 宜人性：伤害他人的代价权重
    pub neuroticism: f64,        // 神经质：不确定性/损失的惩罚权重
}
```

### 决策循环（完整）

```
每tick，对每个agent（按id排序）：

  1. 更新感知（从信息层接收新InfoPacket）
  
  2. 计算预测误差
     predicted = brain.predict(perception)  // 我预期世界是什么样
     actual = perception.current()           // 我感知到世界是什么样
     error = |predicted - actual|
     
     // 情绪更新：预测误差→情绪
     valence += -error × 0.3  // 意外→负面
     arousal = error           // 意外→唤醒
     valence 自然回归0（每tick ×0.95衰减）
  
  3. 判断：惯性还是决策？
     threshold = 0.1 + conscientiousness × 0.1 - neuroticism × 0.05
     if error < threshold && routine.is_some():
       → 继续惯性行为（不跑FEP）
       → 执行routine（日常：种地/贸易/修炼/巡逻）
       → return
     
     // 预测误差高 → 主动决策
  
  4. 构建观测向量
     obs = {
       economic: 我的库存/deficit/surplus/价格,
       military: 我的力量/邻居力量/联盟,
       social: 对每个相关entity的trust/dependence,
       internal: 成员满意度/分裂风险,
       informational: 不确定性/信息时效,
       emotional: valence/arousal,
       cultural: 持有模因,
       counterfactual: 过去决策的后悔值,
     }
  
  5. 生成候选行动（从状态派生）
     candidates = generate_candidates(obs)
     
  6. FEP评估每个候选
     for each candidate:
       efe = expected_free_energy(obs, candidate)
       // 性格调制
       efe += personality_modulation(efe, candidate, personality)
       // 情绪调制
       efe += emotional_modulation(efe, candidate, valence, arousal)
       // 模因调制
       efe += meme_modulation(efe, candidate, meme_profile)
       // ToM调制（对target的信任影响合作/对抗的预期）
       efe += tom_modulation(efe, candidate, theory_of_mind)
       // 反事实调制（过去类似行动的后悔）
       efe += counterfactual_modulation(efe, candidate, regrets)
  
  7. 非理性调制
     // 损失厌恶：涉及"失去"的候选，代价×(1+neuroticism×0.5)
     // 现状偏见：Continue候选 bonus = conscientiousness×0.15
     // 社会学习：高trust对象最近选的行动 bonus = agreeableness×0.1
     // 情绪劫持：arousal>0.85时只看前3个候选（注意力窄化）
     // 愤怒：valence<-0.7时攻击行动代价×0.5
  
  8. 选择
     选EFE最低的候选
     同分→按action_id字典序
     探索：以ε概率选次优（ε由注入rng，ε = openness×0.1）
  
  9. 设置新routine
     agent.routine = chosen_action
     agent.last_decision_tick = now
```

## 六、社会关系（世界的连接组织）

### 现实

- 关系从交互中涌现（不是预分配的）
- 信任靠反复正向交互积累，一次背叛可以摧毁
- 关系有传递性（朋友的朋友、敌人的敌人）
- 关系影响信息流（只信高trust源）
- 关系影响决策（不攻击高trust对象，除非极端条件）
- 社交网络有结构（核心/边缘、桥接、孤岛）

### 万象机制

```rust
/// 全局交互记忆（BTreeMap<(id_a, id_b), InteractionMemory>）
pub struct InteractionMemory {
    pub records: Vec<InteractionRecord>,
    pub trust: f64,              // 衰减加权（每tick重算）
    pub dependence_a: f64,       // A对B的资源依赖
    pub dependence_b: f64,       // B对A的资源依赖
    pub interaction_count: u64,  // 总交互次数
    pub last_interaction: u64,   // 最后交互tick
}

pub struct InteractionRecord {
    pub tick: u64,
    pub event_id: String,
    pub valence: f64,       // 对记录持有者的正/负
    pub magnitude: f64,     // 影响大小（战争=1.0，小贸易=0.05）
}
```

### trust 计算

```
trust(A→B) = Σ(valence_i × magnitude_i × λ^(now-tick_i)) 
           / Σ(magnitude_i × λ^(now-tick_i))
λ = 0.95

特性：
- 近期权重大（去年的事影响小）
- 大事件权重高（一次战争 > 十次小贸易）
- 范围 [-1, 1]
- 无交互 → trust = 0（中性）
- 只增不删（历史不可抹去，但可以衰减到接近0）
```

### 关系传递

```
每tick（或每N tick，节省计算）：
  对每个agent A：
    对A的每个高trust联系人B（trust>0.5）：
      对B的每个高trust联系人C（trust>0.5）：
        如果A和C无直接交互：
          A对C的初始trust += 0.05 × trust(A,B) × trust(B,C)
          （朋友的朋友，微弱正面）
      对B的每个低trust联系人C（trust<-0.5）：
        如果A和C无直接交互：
          A对C的初始trust -= 0.03 × trust(A,B) × |trust(B,C)|
          （朋友的敌人，微弱负面）
```

### 关系如何影响一切

- **贸易**：trust > 0.3 才贸易。trust 越高贸易条件越优惠。
- **信息**：只从高 trust 源接受信息。低 trust 源的信息被忽略或怀疑。
- **联盟**：trust > 0.6 + shared_threat > 0.5 → 结盟。
- **攻击**：攻击高 trust 对象的 EFE 包含巨大代价（失去未来合作 + 声誉损失）。
- **背叛**：背叛后 trust 暴跌（valence=-1, magnitude=1.0），且传播（B 告诉其他人"A 背叛了我"→ 其他人对 A 的 trust 也下降）。

## 七、制度与惯性（世界大部分时间的运转方式）

### 现实

- 大部分社会行为由制度驱动（法律、市场、官僚、规范）
- 制度从反复交互中结晶
- 制度一旦形成有巨大惯性（不需要每刻重新协商）
- 制度降低交易成本（不用每次重新建立信任）
- 制度崩溃是大事件（战争、革命、经济危机）
- 制度之间可能冲突（贸易协定 vs 军事禁运）
- 制度有路径依赖（早期选择锁定后续可能性）

### 万象机制

```rust
pub struct Institution {
    pub id: String,
    pub kind: String,                  // 自由字符串，不枚举
    pub participants: Vec<String>,
    pub formed_tick: u64,
    pub strength: f64,                 // 平均trust × log(持续tick) × 参与数
    pub auto_behavior: Action,         // 制度下自动执行的行为
    pub obligations: Vec<(String, String)>,  // (参与者, 义务描述)
    pub violation_count: u64,          // 被违反次数（多了→strength下降→崩溃）
}
```

### 制度涌现条件

```
// 贸易协定
if 两势力连续 20 tick 贸易（同路线） && trust > 0.6:
  → Institution { kind: "贸易协定", auto_behavior: Trade{..} }
  → 之后贸易自动执行，不需要FEP决策

// 军事同盟
if 两势力 3 次以上共同作战（同一方） && trust > 0.7:
  → Institution { kind: "军事同盟", auto_behavior: MutualDefense{..} }
  → 一方被攻击时另一方自动援助

// 朝贡/附庸
if A 对 B 的 dependence > 0.8 && trust > 0.3 && B.power > A.power × 2:
  → Institution { kind: "朝贡", auto_behavior: Tribute{..} }
  → A 每tick给B资源，B提供保护

// 市场
if 3+ 势力在同一地点贸易 && 持续 30 tick:
  → Institution { kind: "市场", auto_behavior: OpenMarket{..} }
  → 任何势力都可以在此贸易（不需要双边trust）
```

### 制度惯性

```
每tick：
  对每个制度（按id排序）：
    执行 auto_behavior（不需要任何agent做FEP决策）
    strength 自然衰减 ×0.999（不维护会弱化）
    正向交互（贸易成功/互助成功）→ strength += 0.01
    违反（一方未履行义务）→ violation_count += 1, strength -= 0.1
    
    if strength < 0.2:
      制度崩溃 → 事件"XX协定瓦解"
      → 所有参与者的预测误差飙升（惯性被打破）
      → 回到FEP主动决策模式
```

### 制度冲突

```
如果 agent A 同时参与：
  - 与B的贸易协定（义务：持续贸易）
  - 与C的军事同盟（义务：对B禁运）
→ 制度冲突 → A的预测误差上升（两个制度给出矛盾指令）
→ FEP决策：退出哪个？（计算退出的代价：失去贸易利润 vs 失去军事保护）
→ 退出一个 → 该制度strength下降 → 可能崩溃
```

## 八、政治与权力（世界的组织方式）

### 现实

- 势力不是铁板一块（内部有派系、有不满、有野心家）
- 权力需要合法性（纯暴力不稳定）
- 领袖性格影响势力方向
- 继承是危险时刻（权力真空）
- 扩张有管理成本（帝国过度扩张）
- 被征服者不服从（整合成本）
- 官僚/制度约束领袖（不能为所欲为）

### 万象机制

```
每tick，对势力内每个成员（按id排序）：

  // 满意度计算
  satisfaction = weighted_sum(
    my_resource_share / average_share,     // 公平感（权重0.3）
    faction_security,                       // 安全感（权重0.25）
    trust_toward_leader,                    // 对领袖信任（权重0.25）
    cultural_alignment,                     // 模因一致度（权重0.1）
    personality_factor,                     // 性格（agreeableness高→更容忍）（权重0.1）
  )
  
  // 满意度影响行为
  if satisfaction > 0.6: 正常（惯性行为）
  if satisfaction 0.3-0.6: 消极（产出×0.7）
  if satisfaction < 0.3: 预测误差积累 → 最终触发FEP决策：
    候选：
      - 忍耐（conscientiousness高→更可能）
      - 叛逃（有外部高trust势力→更可能）
      - 密谋（内部有多个不满者→更可能）
      - 刺杀领袖（极端：neuroticism高+arousal高+无其他选项）

  // 政变
  if 多个成员同时选择"密谋"且指向同一目标（领袖）：
    政变发生
    成功率 = 密谋者总power / 领袖忠诚者总power
    成功 → 新领袖（密谋者中power最高）→ 势力决策风格可能突变
    失败 → 密谋者被清洗（死亡/叛逃）→ 领袖trust对所有人下降（恐惧）
```

### 继承

```
领袖死亡：
  if 有继承制度（Institution{kind:"继承法"}）：
    → 沿制度走（指定继承人）→ 惯性
  else：
    → 权力真空 → 所有高power成员的FEP同时启动
    → 各自评估："争夺领袖" vs "支持某人" vs "趁机独立"
    → 可能内战（多tick过程）
    → 可能和平过渡（如果某人power压倒性）
    → 可能分裂（多人同时独立）
  
  新领袖性格不同 → 势力FEP决策风格突变
  → 外部势力ToM更新："这个势力变了"→ 重新评估关系
```

### 合法性

```
领袖的"合法性"（不是硬编码，是从多因素涌现）：
  legitimacy = f(
    在位时间（越久越合法——惯性）,
    军事胜利（打赢了→合法）,
    经济表现（成员富裕→合法）,
    继承方式（制度继承>政变>篡位）,
    文化认同（持有主流模因→合法）
  )
  
  legitimacy低 → 成员satisfaction的"对领袖信任"项天然低 → 更容易不满 → 更容易政变
  legitimacy高 → 即使短期困难（战争/饥荒），成员也容忍（"合法领袖暂时困难"）
```

## 九、冲突与战争（世界的暴力面）

### 现实

- 战争不是瞬间事件，是持续过程
- 战争有原因（资源/安全/意识形态/误判）
- 战争有升级逻辑（小冲突→全面战争）
- 战争消耗资源（双方都受损）
- 战争有内部政治效应（不满→反战→政变）
- 战争有外部效应（第三方介入/趁火打劫/调停）
- 战争结束方式多样（歼灭/谈判/僵持/政变中止）
- 战后秩序需要重建（新制度）

### 万象机制

```rust
pub struct WarProcess {
    pub id: String,
    pub attacker: String,
    pub defender: String,
    pub started_tick: u64,
    pub cause: String,              // 自由文本（从因果链派生，非枚举）
    pub progress: f64,              // 0→1
    pub phase: WarPhase,
    pub battles: Vec<BattleRecord>, // 子事件
    pub attacker_commitment: f64,   // 投入资源比例
    pub defender_commitment: f64,
    pub casualties: (f64, f64),     // 双方累计损失
    pub third_parties: Vec<(String, f64)>,  // 介入方及立场
}

pub enum WarPhase {
    Escalation,     // 升级期（小规模冲突、外交最后通牒）
    ActiveCombat,   // 交战期（主要战斗）
    Stalemate,      // 僵持（双方消耗但无决定性进展）
    Negotiation,    // 谈判（某方FEP算出继续打不划算）
    Resolution,     // 解决（条约/投降/吞并/政变中止）
}
```

### 战争如何开始

```
不是"tension > 0.4 → war"。是：

领袖FEP决策"对X采取行动"（因为资源短缺/安全威胁/误判）
  → 候选中有 Seize/PreemptiveStrike
  → FEP算出攻击的EFE最低（因为：军事优势大/对方不可信/资源急需/性格aggressive）
  → 选择攻击
  → 事件"宣战" → 启动 WarProcess

战争原因不是枚举，是因果链：
  caused_by 追溯到根因（"资源枯竭→deficit→贸易被拒→FEP选择武力"）
  描述从因果链自然生成，不是从6种WarCause里选
```

### 战争如何进行（多tick过程）

```
每tick，对每个 WarProcess：
  
  // 战斗计算
  attacker_power = military × commitment × morale × supply_line_factor
  defender_power = military × commitment × morale × terrain_defense_bonus
  outcome_ratio = attacker_power / (attacker_power + defender_power)
  
  // 推进
  progress += (outcome_ratio - 0.5) × speed_factor
  // progress > 0.8 → 攻方即将胜利
  // progress < 0.2 → 守方即将胜利
  // 0.4-0.6 持续多tick → Stalemate
  
  // 消耗（每tick）
  双方资源 -= commitment × upkeep（经守恒律 dissipate）
  casualties += 战斗烈度
  
  // 内部政治效应
  双方成员satisfaction -= casualties_rate × sensitivity
  如果satisfaction过低 → 反战 → 可能政变中止战争
  
  // 第三方（FEP决策）
  外部势力观察到战争 → ToM更新 → FEP评估：
    加入攻方？（如果和守方有仇）
    加入守方？（如果和攻方有仇/联盟义务）
    趁火打劫？（攻击双方中较弱者的其他领土）
    调停？（如果战争损害自己贸易利益）
    观望？（最常见）
  
  // 结束条件
  if progress > 0.9: 攻方胜利 → 谈判/投降/吞并
  if progress < 0.1: 守方胜利 → 攻方撤退/赔偿
  if stalemate > 30 tick: 双方FEP可能选择谈判（消耗太大）
  if 一方政变: 新领袖可能选择停战（性格不同）
  
  // 战后
  → 条约（新Institution）/ 领土变更 / 资源转移 / 附庸关系
  → 所有相关方交互记忆更新（valence由结果决定）
  → 模因注入（"战争荣耀"/"和平主义"取决于结果）
```

## 十、文化与模因（世界的意义层）

### 现实

- 文化从历史中生长（不是预设的）
- 文化影响决策偏好（价值观）
- 文化通过社交传播（模仿、教育、宣传）
- 文化分化产生认同（我们vs他们）
- 文化冲突是真实的冲突源
- 文化变迁是缓慢的（代际）
- 重大事件产生文化冲击（战争创伤、技术革命）

### 万象机制

已实现（meme.rs），需接线：

```
模因生命周期：
  产生：重大事件（importance >= Important）→ 映射为模因注入池
  传播：沿社交网络（高trust路径快）+ 地理邻接
  感染：agent接触模因 → 如果与现有模因兼容 → 接受；不兼容 → 免疫抵抗
  影响：持有模因 → 调制FEP reward权重
  变异：传播中小概率变异（注入rng）→ 新变体
  选择：适应度低的模因自然消亡（持有者少→传播机会少）
  死亡：如果所有持有者死亡/放弃 → 模因灭绝

模因如何影响决策（连续调制，非硬编码）：
  持有"武力至上" → 攻击行动EFE -= 0.15（奖励加成）
  持有"贸易共赢" → 贸易行动EFE -= 0.10
  持有"孤立主义" → 结盟行动EFE += 0.10（惩罚）
  持有"天命扩张" → 扩张行动EFE -= 0.12
  
  模因向量 × 行动类型 → 连续权重矩阵 → 调制EFE
  不是"if meme == X then Y"——是向量内积，平滑连续

文化分化：
  不同势力经历不同事件 → 注入不同模因 → 模因池分化
  → 决策风格分化 → 行为模式分化 → 互相不理解（ToM建模困难）
  → 文化冲突（模因不兼容的势力间trust天然低）
```

## 十一、技术与创新（世界的变化引擎）

### 现实

- 技术改变生产函数（同样投入产更多）
- 技术改变军事平衡（新武器）
- 技术扩散有路径（贸易/间谍/迁移）
- 技术突破是偶然的（探索的副产品）
- 技术颠覆既有秩序（旧势力衰落、新势力崛起）
- 技术有路径依赖（早期选择锁定方向）

### 万象机制

```rust
pub struct Technology {
    pub id: String,
    pub name: String,              // 题材命名
    pub domain: String,            // "生产"/"军事"/"信息"/"医疗"
    pub effect: TechEffect,        // 改变什么
    pub discovered_by: String,     // 谁发现的
    pub discovered_tick: u64,
    pub diffusion: Vec<String>,    // 已扩散到哪些势力
}

pub enum TechEffect {
    ProductionBoost { resource: String, multiplier: f64 },
    MilitaryBoost { multiplier: f64 },
    InformationSpeed { multiplier: f64 },
    CarryingCapacityBoost { multiplier: f64 },
    NewResourceAccess { resource: String },  // 解锁新资源利用
}
```

### 技术如何产生

```
FEP决策"Research" → 启动 OngoingProcess{kind:"技术攻关"}
  每tick：投入资源 → progress += speed（由投入量和人才决定）
  完成时：
    发现什么由（当前已有技术 + 投入domain + 种子rng）决定
    → 新技术进入世界
    → 改变发现者的生产函数/军事能力
    → 事件"技术突破"（importance: Important+）
    → 模因注入（"创新精神"）

偶然发现：
  FEP决策"Explore" → 小概率（种子rng）发现新技术/新资源
  → 不是"每N tick必出技术"——是探索的副产品
```

### 技术扩散

```
技术不会自动传播。扩散路径：
  - 贸易：有贸易关系的势力间，小概率每tick扩散（信任越高越快）
  - 间谍：FEP决策"窃取技术"（如果有信息通道）
  - 迁移：叛逃者/移民携带技术
  - 战争：征服者获取被征服者技术

扩散改变世界格局：
  某势力垄断技术 → 生产/军事优势 → 其他势力FEP决策"必须获取"
  → 贸易/间谍/战争 → 技术扩散 → 优势消失 → 新均衡
```

## 十二、时间尺度与过程（世界不是瞬间的）

### 现实

- 不同事情有不同时间尺度
- 战斗：几小时（1-2 tick）
- 贸易谈判：几周（3-5 tick）
- 战争：几月到几年（10-50 tick）
- 技术攻关：几年（20-40 tick）
- 文化变迁：几代人（100+ tick）
- 制度形成：反复交互（20-50 tick）
- 经济周期：几十年（climate_period tick）

### 万象机制

```rust
pub struct OngoingProcess {
    pub id: String,
    pub kind: String,
    pub started_tick: u64,
    pub participants: Vec<String>,
    pub progress: f64,             // 0.0 → 1.0
    pub speed: f64,                // 每tick推进（由投入决定）
    pub sub_events: Vec<String>,   // 过程中产生的子事件
    pub state: String,             // 当前子状态
    pub resolution: Option<String>,
}
```

所有非瞬时行动都是过程：
- 贸易谈判（3-5 tick）→ 成功→新贸易路线 / 失败→关系恶化
- 战争（10-50 tick）→ 见第九节
- 技术攻关（20-40 tick）→ 成功→新技术 / 失败→资源浪费
- 领土整合（20-30 tick）→ 被征服者trust缓慢上升→产出恢复
- 迁徙（5-10 tick）→ 人口从A到B（途中有损耗）
- 制度改革（10-20 tick）→ 旧制度弱化→新制度结晶

过程中：
- 参与者持续投入资源（守恒律）
- 内部政治持续作用（成员可能反悔/政变）
- 外部势力持续观察（可能介入）
- 信息持续传播（过程进展被外界感知）
- 可以被打断（政变/外部攻击/资源耗尽）

## 十七、成功标准

seed=42, xianxia, 3000 tick：

1. 节奏：70%+ tick 是平静日常（制度运转），30% 是动荡（危机/冲突/变革）
2. 事件多样：贸易/外交/战争/叛逃/政变/技术/探索/瘟疫/迁移/制度改革/文化冲突 均自然出现
3. 经济真实：不同势力产不同资源、贸易互补、价格波动、短缺驱动冲突、垄断产生权力
4. 战争有深度：多tick过程、有因果链、有内部政治、有第三方、有战后秩序
5. 角色有差异：不同性格做不同选择、有误判、有成长/黑化
6. 关系涌现：trust网络从交互形成、有背叛、有联盟、有仇敌
7. 制度可见：贸易协定/联盟/朝贡/市场 从历史结晶、有崩溃
8. 文化分化：不同势力持有不同模因、决策风格可观测不同
9. 信息局部：角色不知道远处事件、有谣言、有欺骗、有信息差
10. 空间有意义：距离影响贸易/军事/信息、地形影响通行
11. 人口动态：有迁移、有承载力约束、有周期波动
12. 技术变化：有突破、有扩散、有颠覆
13. 不收敛：3000 tick后 ≥ 3势力、无monopoly
14. 因果完整：任何事件可追溯到根因
15. 确定性：同seed逐字节一致、drift=0
