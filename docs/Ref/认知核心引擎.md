# 认知核心引擎（cognitive_core_rs）

> 独立认知核心引擎，提供感知、记忆、推理、决策、学习五大认知功能的统一抽象层，可脱离 MindCore 单独集成到任意 Rust 项目中。

## 概述

认知核心引擎（`cognitive_core_rs`）是万象认知体系的"大脑中枢"，核心代码 `lib.rs` 约 25KB，是整个体系中体积最大、抽象层次最高的独立 Rust 库。它将认知过程分解为五个可组合的阶段，每个阶段都是独立的 trait，允许用户按需替换实现。

**设计哲学**：认知不是单一算法，而是一组可插拔的协作模块。你可以只使用记忆模块，也可以组装完整的认知流水线。

## 核心架构

### 认知流水线

```
感知输入 → 记忆存取 → 推理计算 → 决策输出 → 学习更新
   ↓           ↓          ↓          ↓          ↓
Perceive    Recall     Reason     Decide     Learn
```

### 模块总览

| 模块 | 职责 | 核心 Trait |
|------|------|-----------|
| `perception` | 感知输入处理与特征提取 | `Perceiver` |
| `memory` | 工作记忆、情景记忆、语义记忆 | `MemoryStore` |
| `reasoning` | 演绎/归纳/类比推理 | `Reasoner` |
| `decision` | 多目标决策与行动选择 | `DecisionMaker` |
| `learning` | 在线参数调整与策略优化 | `Learner` |
| `pipeline` | 认知流水线编排 | `CognitivePipeline` |

### 核心接口

```rust
/// 认知核心主入口
pub struct CognitiveCore {
    perceiver: Box<dyn Perceiver>,
    memory: Box<dyn MemoryStore>,
    reasoner: Box<dyn Reasoner>,
    decision: Box<dyn DecisionMaker>,
    learner: Box<dyn Learner>,
    pipeline: CognitivePipeline,
}

impl CognitiveCore {
    /// 完整认知循环
    pub fn think(&mut self, input: Perception) -> Result<CognitiveOutput> {
        let features = self.perceiver.perceive(input)?;
        let memories = self.memory.recall(&features)?;
        let reasoning = self.reasoner.reason(&features, &memories)?;
        let decision = self.decision.decide(&reasoning)?;
        self.learner.learn(&decision, &features)?;
        Ok(decision)
    }

    /// 仅使用推理（跳过感知和学习）
    pub fn reason_only(&self, context: &Context) -> Result<ReasoningResult>;

    /// 仅使用记忆检索
    pub fn recall(&self, query: &MemoryQuery) -> Result<Vec<Memory>>;
}
```

## 详细说明

### 感知模块（Perception）

将原始输入转化为内部特征表示。

```rust
pub trait Perceiver {
    /// 处理原始输入，输出特征向量
    fn perceive(&mut self, input: Perception) -> Result<FeatureVector>;

    /// 注意力过滤 — 只保留相关特征
    fn attend(&self, features: &FeatureVector, focus: &AttentionFocus) -> FeatureVector;
}

pub enum Perception {
    Symbolic(Vec<Symbol>),        // 符号化输入
    Vector(Vec<f64>),             // 数值向量
    Structured(StructuredInput),  // 结构化输入（图/树）
}
```

**内置实现**：
- `StatisticalPerceiver`：基于统计特征提取
- `AttentionPerceiver`：基于注意力机制的特征选择
- `CompositePerceiver`：多感知器级联

### 记忆模块（Memory）

三层记忆架构，模拟人类认知记忆系统。

```rust
pub trait MemoryStore {
    /// 存入记忆
    fn store(&mut self, memory: Memory) -> Result<MemoryId>;

    /// 检索记忆
    fn recall(&self, query: &MemoryQuery) -> Result<Vec<Memory>>;

    /// 记忆衰减与巩固
    fn consolidate(&mut self) -> Result<()>;

    /// 遗忘
    fn forget(&mut self, criteria: ForgetCriteria) -> Result<usize>;
}

pub enum Memory {
    /// 工作记忆 — 当前活跃的信息（容量有限）
    Working(WorkingMemory),
    /// 情景记忆 — 具体事件经历
    Episodic(EpisodicMemory),
    /// 语义记忆 — 抽象知识与概念
    Semantic(SemanticMemory),
}

pub struct WorkingMemory {
    pub items: Vec<MemoryItem>,
    pub capacity: usize,  // 默认 7±2
    pub decay_rate: f64,
}
```

**记忆检索策略**：

| 策略 | 描述 | 适用场景 |
|------|------|---------|
| `SimilaritySearch` | 余弦相似度匹配 | 模糊回忆 |
| `TemporalRecency` | 时间近因优先 | 序列决策 |
| `SpreadingActivation` | 激活扩散网络 | 联想记忆 |
| `ExactMatch` | 精确键值匹配 | 事实检索 |

### 推理模块（Reasoning）

支持多种推理模式。

```rust
pub trait Reasoner {
    fn reason(&self, context: &Context, memories: &[Memory]) -> Result<ReasoningResult>;
}

pub enum ReasoningMode {
    Deductive,   // 演绎推理：从一般到特殊
    Inductive,   // 归纳推理：从特殊到一般
    Abductive,   // 溯因推理：最佳解释推断
    Analogical,  // 类比推理：结构映射
}

pub struct ReasoningResult {
    pub conclusions: Vec<Conclusion>,
    pub confidence: f64,
    pub reasoning_chain: Vec<InferenceStep>,
    pub alternatives: Vec<AlternativeHypothesis>,
}
```

### 决策模块（Decision）

多目标、多约束下的行动选择。

```rust
pub trait DecisionMaker {
    fn decide(&self, reasoning: &ReasoningResult) -> Result<CognitiveOutput>;
}

pub struct DecisionConfig {
    pub strategy: DecisionStrategy,
    pub exploration_rate: f64,  // ε-greedy 探索率
    pub risk_aversion: f64,     // 风险厌恶系数
    pub time_horizon: usize,    // 前瞻步数
}

pub enum DecisionStrategy {
    MaxUtility,       // 最大效用
    ExpectedValue,    // 期望值
    Minimax,          // 最小最大（最坏情况最优）
    Satisficing,      // 满意解（达到阈值即停）
    WeightedSum,      // 加权求和
}
```

### 认知流水线（CognitivePipeline）

将五个阶段编排为可配置的流水线。

```rust
pub struct CognitivePipeline {
    stages: Vec<PipelineStage>,
    config: PipelineConfig,
}

pub struct PipelineConfig {
    pub skip_perception: bool,    // 使用预提取特征
    pub skip_learning: bool,      // 冻结学习（推理模式）
    pub max_iterations: usize,    // 迭代推理最大轮数
    pub enable_reflection: bool,  // 启用元认知反思
}

impl CognitivePipeline {
    /// 构建自定义流水线
    pub fn builder() -> PipelineBuilder;

    /// 执行单步认知循环
    pub fn step(&mut self, input: Perception) -> Result<CognitiveOutput>;

    /// 迭代推理直到收敛
    pub fn run_until_converge(&mut self, input: Perception, threshold: f64) -> Result<CognitiveOutput>;
}
```

## 应用案例

### 案例 1：简单对话认知

```rust
use cognitive_core_rs::*;

let mut core = CognitiveCore::default();

// 完整认知循环
let output = core.think(Perception::Symbolic(vec![
    Symbol::new("user_intent", "ask_weather"),
    Symbol::new("location", "beijing"),
]))?;

match output.action {
    Action::Respond(content) => println!("回复: {}", content),
    Action::Query(external) => println!("需要查询外部数据: {:?}", external),
    _ => {}
}
```

### 案例 2：自定义认知流水线

```rust
let pipeline = CognitivePipeline::builder()
    .with_perceiver(AttentionPerceiver::new(0.8))
    .with_memory(HierarchicalMemory::new(
        WorkingMemory::with_capacity(7),
        EpisodicMemory::default(),
        SemanticMemory::default(),
    ))
    .with_reasoner(AnalogicalReasoner::new())
    .with_decider(UtilityMaximizer::new())
    .skip_learning()  // 推理模式，不更新参数
    .build();
```

### 案例 3：仅使用记忆模块

```rust
// 认知核心可拆解使用——只用记忆检索
let memory = HierarchicalMemory::default();

memory.store(Memory::Semantic(SemanticMemory {
    key: "rust_ownership".into(),
    content: "Rust 通过所有权系统实现内存安全，无需 GC".into(),
    tags: vec!["rust".into(), "memory".into()],
    strength: 1.0,
}))?;

let results = memory.recall(&MemoryQuery::semantic("Rust 内存管理"))?;
```

## 问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 认知循环超时 | 推理迭代次数过多 | 降低 `max_iterations` 或设置收敛阈值 |
| 工作记忆溢出 | 同时处理信息过多 | 增大 `capacity` 或启用注意力过滤 |
| 记忆检索结果为空 | 查询与存储表示不匹配 | 检查特征提取一致性，使用模糊检索 |
| 决策震荡（反复切换） | 多目标权重接近 | 引入决策滞后（hysteresis）或随机扰动 |
| 学习不收敛 | 学习率过高 | 降低学习率，启用学习率衰减 |
| trait object 性能开销 | 动态分发开销 | 使用泛型静态分发或启用 LTO |
