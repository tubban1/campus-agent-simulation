### 幻灯片 2：项目背景与行业痛点 (Background & Pain Points)
**为什么我们需要一个全新的平行世界？**
- **当前 AI Agent 发展的瓶颈**：大多停留在单次任务闭环或“一问一答”模式，缺乏在连续时间轴和物理空间中的长期生存能力。
- **人文社科研究的痛点**：
  - 社会学、心理学、行为学实验往往**成本高昂**、**受制于伦理边界**，且**样本难以在相同条件下复现**。
  - 传统计算机模拟（如基于方程的宏观模型）缺乏真实的微观个体“心智”与“认知差异”。
- **我们的解法**：用底层大语言模型赋予个体心智，用沙盘规则赋予物理与社会边界，构建一个大规模、可控、高仿真的平行社会基座。

### 幻灯片 3：愿景与终极形态 (Vision)
**构建由 Agent 与真实环境交织的平行世界**
- **长远愿景**：打破物理世界与数字世界的边界，打造一个基于真实环境、具备自我演化能力的平行空间系统。
- **核心理念**：它不是离散的“回合制模拟工具”，而是一个时刻在运转、有昼夜交替、与真实世界时间完全同频的“活体数字世界”。
- **虚实交融**：虚拟世界的运转规律脱胎于真实物理规则，而真实世界的信息（天气、新闻、政策）则持续作为“扰动”注入平行空间。

### 幻灯片 4：商业定位 (Business Value)
**为人文社科打造的新一代“计算型科研基座”**
- **核心应用场景**：为行为学、信息传播学、社会学、心理学等领域提供“所见即所得”的数字化实验场。
- **受控实验变量**：研究人员可以精准抛入环境变量（如：突发舆论冲击、极端天气、资源紧缺、制度变化），从而观察群体动态的自然涌现。
- **高精度数据产出**：系统可自动化导出多维度实验数据，生成高精度的**交互图谱**、**情绪流变图**与**行动轨迹序列**，直接赋能计算社会学 (Computational Social Science) 论文产出与研究。

### 幻灯片 5：落地起点——“平行校园”生态模型
**以高度结构化的微观社会作为切入点**
- 为什么选择校园？
  - **边界清晰**：物理范围可控，人群结构相对单纯。
  - **规律性强**：拥有完整的作息制度（上课、考试、就寝）和明确的资源分布。
- **当前的沙盘设定**：映射了真实的校园设施，包含 20+ 个拥有不同人格、身份和背景的师生 Agent，在校园中自主生活、学习和社交。

### 幻灯片 6：自主循环基石（一）—— 空间拓扑与物理约束
**用物理边界规范数字生命的行为**
- **真实的物理映射**：涵盖宿舍、教学楼、图书馆、食堂、商业街等功能性空间。
- **属性与约束**：
  - 每个空间拥有**容量上限**与**开放时间段**。
  - 具备真实的**距离成本**，Agent 跨区域行动需要付出时间。
- **环境涌现**：空间的**拥挤度**会实时变动。过高的拥挤度会引发 Agent 的压力反馈，促使其改变计划（如放弃去爆满的食堂就餐）。

---

### 幻灯片 7：自主循环基石（二）—— 经济模型与资源约束
**用生存与需求驱动社会行为**
- **微观经济循环**：系统引入了货币、物品库存与基础的资源交易机制。
- **生存压力分配**：
  - Agent 必须通过消费（如去食堂买饭、去商业街购物）来维持精力与状态。
  - 当 Agent 面临“预算短缺”时，资源约束会迫使他们进行兼职、社交求助、甚至是资源的争夺。
- **宏观反馈**：这种资源依赖，成为推动整个沙盘脱离人工干预、实现永续演化的最核心内在动力。

---

### 幻灯片 8：自主循环基石（三）—— 涌现式社会关系网络
**从“硬编码关系”走向真实的“社会沉淀”**
- **拒绝预设剧本**：我们不提前设定“张三和李四一定是朋友”，只提供关系的“生成条件”（如：同在一个社团、在图书馆偶遇、争夺同一资源）。
- **动态关系指标**：关系从底层的“互动证据”开始，逐步沉淀出**信任度**、**好感度**、**竞争感**与**冲突值**。
- **群体聚散涌现**：这些关系数据反过来影响他们后续的结伴意愿、帮助概率，甚至是群体性事件中的阵营划分。

---

### 幻灯片 9：自主循环基石（四）—— 信息传播与外部映射
**信息是数字社会的血液**
- **虚实同步**：同步清华所在区域的北京实时天气及外部真实 RSS 资讯。
  - *例如*：现实降雨会立刻降低数字校园中“操场”的活跃度，增加图书馆的人流。
- **失真与传播网络**：
  - 外部新闻或校园公告不会采取“上帝视角全服广播”。
  - 而是作为种子信息，经由特定的少数 Agent 接收，随后顺着他们的“社交关系网”在校园内自然扩散。在这期间，信息还可能发生误解与失真，形成真实的舆论场。

---

### 幻灯片 10：Agent 认知与决策引擎 (Cognitive Engine)
**建立具备长期记忆与人格连贯性的数字分身**
- **五层目标驱动模型**，突破单次的应激反应：
  1. **稳定倾向**：深层的身份、人格特质、长期需求（不易变）。
  2. **长期方向 (30-180天)**：提供核心生存与奋斗动力。
  3. **中期项目 (7-30天)**：分解后的阶段性任务（如“完成期末论文”）。
  4. **短期承诺 (1-7天)**：对他人或组织的社会契约（如“今晚帮社团值班”）。
  5. **执行计划 (8小时窗口)**：具体的时间表。
- **真实偏差**：Agent 会试图遵循计划，但在执行中会受环境噪音（天气恶劣、遇到朋友）影响，产生合理的**行动偏离**。

### 幻灯片 11：实验的可靠性与学术可信度保障 (Reliability & Validity)
**为什么社科学者可以信任沙盘产生的数据？**
- **防大模型幻觉 (Hard Constraints)**：通过底层空间拓扑与经济规则引擎形成“物理锁”，大模型的决策被严格限制在合法物理法则内，不可能发生瞬移或无中生有。
- **结构化定量人格 (Quantitative Traits)**：Agent 个性并非随意的文本提示，而是映射到（0-100）的稳定参数（如外向性、责任心、风险偏好），确保行为概率分布的一致性与科学性。
- **环境基准数据校准 (Calibration)**：系统的空间流量、作息倾向均可通过引入真实世界的统计数据进行拟合校准，消除纯虚构带来的偏移。
- **完全可溯源与复现 (Traceability & Reproducibility)**：每一条决策、记忆检索、环境反馈均会结构化入库入档；搭配特定的环境快照（Snapshot）和随机种子，即可实现实验条件的 100% 严谨复现。

---

### 幻灯片 12：连续运行引擎 (World Runtime)
**保障大规模 Agent 并发演算的核心架构**
- **连续时间轴 (World Clock & Tick)**：与真实世界的时间轴精准挂钩。
- **混合驱动架构 (Hybrid Engine)**：
  - **大模型 (LLM)** 负责高维度的认知反思、长期计划与复杂对话。
  - **高性能规则引擎**负责 Tick 级别的时空移动、拥挤结算与高频状态推演。
- **注意力触发机制 (Attention Triggers)**：
  - 当研究员（观察者）聚焦特定区域或 Agent 时，系统才会在该局部拉高模型的调用分辨率，极大地兼顾了深度与性能。

### 幻灯片 13：三层权限设计与交互体验
**观测、互动与控制的完美统一**
- 🔭 **观测者 / 研究员 (Observer)**
  - 沉浸式观察沙盘的演进：多维看板监控空间热度、事件流线、阅读“校园日报”。
- 🤝 **参与者 (Participant)**
  - 投入实验变量：以匿名的身份向特定群体散播一条流言，或发起一项新政策倡议，观察整个数字社会的连锁反应。
- ⚙️ **管理员 / 实验设计者 (Admin)**
  - 上帝视角：控制宏观世界规则（强制下雨、调整考试压力阈值、引发资源短缺），并随时为世界保存快照（Snapshot）以供回溯与对比。
